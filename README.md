# 🐾 AnimalVision AI

An AI-powered Animal Recognition application using CLIP.

## Features
- Upload animal images
- AI animal classification
- Top 5 predictions
- Similarity scores
- Animal information
- Interactive Gradio dashboard

## Technologies
- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- CLIP
- Gradio

## Model
openai/clip-vit-base-patch32
